   （ほかの行は足せる。今の Python に近い）
3. **名前が数の行**: 隔てるか、字にして読むか（今の Python は一覧が 500）
4. **E4**: NaN・Infinity・入れ子の行を隔てるか（誤り 1 が直る）、J で読んで答えるか（J。誤り 1 を写す）

### 採点の係の推す答え（別のエージェント・2026-11-12）

1. 画面が送る型は許す表にしてよい。変換表の取り込みにも同じ表を当てるが、字の欄の数・真偽・null は今どおり str() で受け、並び・表だけを断る
   （前の版で書き出したファイルを読めなくしない。画面の外からの並び・表の名前は保存しても役に立たないので断っても失う物が無い）。
2. **その行に触れる書き（PUT・DELETE）だけを止める**。dashboards.json はダッシュボード・カードの設計・セットの 3 つの置き場なので、マスタ全体を止めると
   手で直した 1 行で 3 つの保存が全員止まる（今の Python はこの形の POST を 201 で通している）。条件: next_id と名前の重なりの確かめに隔てた行を含め、
   隔てた行は書き戻す。ファイルの revision が読めないときと表でない行（3.102.0）だけはマスタ全体を止める。
3. **隔てる**（「名前が字ではありません（5）」）。字にして読むと、小数の str() と「書き戻すとき数のままか字か」の決めが 2 つの言語に増える。行はファイルに残る。
4. **分けて答える**。読まない値（知らない鍵・ほかの元の行。E4 の 35 歩のうち 19 歩）は J のまま持って Python と同じ字で書き戻す（Python を変えない・正しい行を消さない）。
   読む欄（中身）の NaN・Infinity・深い入れ子は隔てる（誤り 1 が直る）。J は全部の部品ではなく Store の行の読み書きだけに使う。
5. **直して断る（E3）**。B2 は「消したつもりで残る」（誤り 3）を窓の決まりに焼き込み、段 ④ の後に答えの元の無い所で窓だけを直すことになる。
6. **断ってよい**。dashboards の rows: NaN と結合の NaN は画面から来ない（中身は表、結合は master-join.js が並びで送る）。深い式は式ビルダーが作らない段で、
   上限は同梱の変換表と master_defaults の最大の段より十分大きくする。ただし S の stale_hours は断らず、既定の 36 で続けて帯で言う（実績のタブを止めない）。
